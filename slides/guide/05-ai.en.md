# Each stage, two ways

<div class="sub">Same principles and checks either way</div>

| Stage | By hand | Claude Code |
|---|---|---|
| Plan the talk | `docs/talk-plan.md` | `/kickoff` |
| Set up the deck | the `TODO`s in `slides.md` | `/kickoff` |
| Write slides | `docs/recipes.md`, `pnpm guide` | `/slide` |
| Build a demo | copy `components/guide/ExampleDemo.vue` | `/demo` |
| Second language (optional) | `HANDBOOK.md` | `/translate` |
| Content review | a colleague + `docs/checklists.md` | `/review` |
| Technical check | `pnpm check` | `/preflight` |
| Talk day | `docs/checklists.md` | |

<div class="foot"><lucide-info /> <b>/review</b> is an independent agent that never saw the drafting; it checks the slides' claims against primary sources and never edits</div>

# Growing the template

<div class="sub">Problems found in one deck get fixed for the next</div>

<div class="flow mt-10">
  <div class="step">Find a problem<small>in your deck</small></div>
  <lucide-arrow-right class="arrow" />
  <div class="step">Fix it there<small>in your deck</small></div>
  <lucide-arrow-right class="arrow" />
  <div class="step lit">Open an issue<small>what and why</small></div>
  <lucide-arrow-right class="arrow" />
  <div class="step">Template updated<small>from the next deck on</small></div>
</div>

<div class="notes">

- **No backward compatibility**: each deck is a snapshot of the template when it was created. Old decks aren't updated
- **The AI helps**: when it fixes something template-level, it flags it as worth reporting

</div>
