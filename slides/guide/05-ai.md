# 各段階の進め方

<div class="sub">どちらの道でも同じ原則とチェックを使います</div>

| 段階 | 手作業 | Claude Code |
|---|---|---|
| 構成を決める | `docs/talk-plan.md` | `/kickoff` |
| 骨組みを埋める | `slides.md`の`TODO` | `/kickoff` |
| スライドを書く | `docs/recipes.md`、`pnpm guide` | `/slide` |
| デモを作る | `components/guide/ExampleDemo.vue`をコピー | `/demo` |
| 第二言語（任意） | `HANDBOOK.md` | `/translate` |
| 内容のレビュー | 同僚 + `docs/checklists.md` | `/review` |
| 技術チェック | `pnpm check` | `/preflight` |
| 発表当日 | `docs/checklists.md` | |

<div class="foot"><lucide-info /> <b>/review</b>は執筆の経緯を知らない独立したエージェントで、スライドの主張を一次情報で確かめます。編集はしません</div>

# テンプレートを育てる

<div class="sub">デッキごとに見つかった問題を、次のデッキのために直します</div>

<div class="flow mt-10">
  <div class="step">問題を見つける<small>自分のデッキで</small></div>
  <lucide-arrow-right class="arrow" />
  <div class="step">その場で直す<small>自分のデッキで</small></div>
  <lucide-arrow-right class="arrow" />
  <div class="step lit">Issueで報告<small>何をなぜ直したか</small></div>
  <lucide-arrow-right class="arrow" />
  <div class="step">テンプレートに反映<small>次のデッキから</small></div>
</div>

<div class="notes">

- **後方互換はありません**：各デッキは作成時点のスナップショットです。既存のデッキは更新しません
- **AIも手伝います**：テンプレート側の問題を直したときは、AIが報告すべき点として伝えます

</div>
