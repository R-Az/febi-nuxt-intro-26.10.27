## 気づいたこと

- 打刻漏れの画面は、起動直後は「まだ検出された打刻漏れはありません」「まだ実行されていません」と空で、初期データの打刻漏れ2件は手動で検出するまで出ない（定期処理は0時にしか動かないため。仕様どおりだが、デモでは手動実行が要る）。
- 「今すぐ検出」の対象日の初期値は前日。初期データの打刻漏れのうち先月分（E002 9/17）は、対象日を手で選ばないと検出されない。
- 従業員の勤怠一覧の休憩合計（10月 15:00）は打刻漏れの日の休憩も含む。実働・残業の合計には含めないので計算は正しいが、合計行の中で扱いがそろっていない。
- 出勤日数には打刻漏れの日と今日（勤務中・退勤済み）も入る（README に記載あり）。
- `npm ci` で esbuild と fsevents の install scripts が許可待ちの警告になったが、開発サーバー・ビルドには影響しなかった。
