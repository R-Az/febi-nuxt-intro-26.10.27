## 気づいたこと

- 同意前でも `window.dataLayer` と `gtag` 関数があり、`js`・`config` の2件が積まれている。gtag.js を読み込まないので送信はされないが、手順書の「同意前に dataLayer がない」という見方では当てはまらない。同意すると積まれていた `config` がそのまま使われる。
- 1段目（nuxt-1）と同じく、打刻漏れの画面は起動直後は空で、初期データの打刻漏れは手動で検出するまで出ない。「今すぐ検出」の対象日の初期値は前日で、先月分（E002 9/17）は日付を選び直す必要がある。
- 幅841pxの画面では、ナビゲーションがハンバーガーメニューに畳まれ、勤怠一覧などへはメニューを開いて移動する。
- 勤怠一覧の休憩合計は打刻漏れの日の休憩も含む（実働・残業の合計には含めない）。1段目から変わっていない。
- `npm ci` で一部パッケージの install scripts が許可待ちの警告になったが、開発サーバー・ビルドには影響しなかった。
