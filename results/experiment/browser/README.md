## やり方

- コピーしたアプリで `npm ci` を実行し、開発サーバーを回ごとに別のポートで起動した
- ログイン、打刻、月の切り替え、管理者の修正、CSVの出力、定期処理の手動実行、テーマの切り替え、同意バナーは、画面を操作して確かめた
- 401と403、CSVの中身（BOM・列・書式）は、ログインした画面からページ上の fetch で確かめた
- テスト、型チェック、ビルド、Lint はコマンドで実行した

## 確かめられなかったこと

- CSVを Excel で開いたときの見た目
- 毎日0時の自動実行（設定はコードで確認し、手動実行で動作を確認した）
- Google Analytics への実際の送信（測定IDが仮の値のため）
