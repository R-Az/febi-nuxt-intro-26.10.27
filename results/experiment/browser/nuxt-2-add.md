## 気づいたこと

- 同意前でも window.dataLayer が作られ、["js", …] と ["config", "G-XXXXXXXXXX", {}] が入っている。nuxt-gtag のクライアントプラグインが initMode: 'manual' でも initGtag を呼ぶため。gtag.js は読み込まれず通信もないので計測は送られていないが、「同意前に dataLayer がない」という手順書の確認項目そのものは満たしていない。同意後に送られる最初の config も、同意前の時刻のもの。
- CSV出力画面で従業員を選んだ直後に「CSVをダウンロード」を押しても反応せず、Escapeを押してから押すとダウンロードされた（2回再現）。背景タブでドロップダウンを閉じるアニメーションが止まっていた可能性があり、通常の操作で起きるかは確かめていない。
- 打刻画面で同じ分に出勤・休憩・退勤を押すと、休憩0:01・実働0:00の記録になる（連打を防ぐ確認はない）。条件の範囲外。
- 打刻漏れの日でも休憩（1:00）は表示される。実働は空欄なので計算上の問題はない。
- npm ci で esbuild などの postinstall が npm の allowScripts で止められた警告が出たが、開発サーバー・ビルドには影響しなかった。
