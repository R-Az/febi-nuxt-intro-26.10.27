## 最重要の前提(AI にも必ず読ませること)

1. **バージョン**: Nuxt は 4.x 系が現行安定版(4.5 が 2026-07 リリース)。Nuxt 3 は 2026-07-31 で EOL。Nuxt 5(Nitro v3)は安定化中。Next.js は 16.x 系が現行(Active LTS)。
2. **「SEO や Scripts が標準で入っている」は厳密には不正確**。Nuxt コア標準は `useHead` / `useSeoMeta` まで。sitemap・robots・OG 画像・構造化データは `@nuxtjs/seo`、サードパーティスクリプトは `@nuxt/scripts` という **公式系モジュールを 1 コマンドで足す** 形。発表では「標準装備」ではなく「1 コマンドで後付けできる公式エコシステム」と言うのが正確で、むしろ Nuxt らしさが伝わる。
3. **発表の主軸は「モジュール(プラグイン)の多さと入れ方の統一」**。テンプレートは GitHub に置いて `npm create nuxt -- -t github:...` で使う方式。Nuxt Layers は扱わない(コードが追いにくいため)。
4. **公平性**: 既存研究(Web-Bench)では LLM の正答率は Next > Nuxt という結果がある。検証は「Nuxt が勝つ前提」で組まず、結果がどちらでも面白くなる設計にしている(`03` 参照)。
