# 構成シート

スライドを作る前に、トークの範囲を決めます（`PRINCIPLES.md`の「進め方」）。下のテンプレートをリポジトリ直下の**`CLAUDE.local.md`**にコピーして記入してください。このファイルはgitignore済みです（デッキの一部ではなく、作業メモのため）。この名前にしておくと、後でAIツールを使う場合にも読み込まれます。`/kickoff`がこれらの質問をして、ファイルを書いてくれます。

## 最初に答える質問

1. **テーマと要点**：聴いた人が*何をできるように、または何を理解できるようになって帰るか*？機能の一覧ではなく、具体的な要点を1つ。
2. **なぜ今か**：ジュニアからシニアまでのフロントエンド開発者に最大50分を使ってもらう価値がある、どんな問題があるか？
3. **導入**：問題から始められるか（困りごと → 素朴な解決策 → より良い道具）？できないなら、その理由。
4. **セクション**：3〜5個。それぞれについて、タイトル、1つの要点（振り返りの1行）、語るのではなく**どう見せるか**：どのデモ（振る舞い）とどの図（構造）を使うか。存在理由がはっきりしないデモには印を付けます。
5. **まとめ**：チートシート、判断表、または3〜5個のポイント。
6. **収まるか**：50分に収まるか？核となる部分にジュニアがついてこられるか？
7. **却下したアイデア**：やめた切り口はすべて、理由を1行添えて書き留めます。後で紛れ込まないようにするためです。
8. **言語**：日本語のメインデッキだけか、第二言語デッキも作るか？どの言語で下書きするか？
